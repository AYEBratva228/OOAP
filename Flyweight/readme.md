**Отличия и проблема**

Нам нужно создать большой объем объектов и на это уходит много памяти. На помощь приходить паттерн Flyweight, который объединяет повторяющиеся данные объектов в тип и либо использует существующий тип, либо запоминает новый тип для дальнейшего использования.
